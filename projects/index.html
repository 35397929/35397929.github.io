01AI 应用

课程知识库问答与学习工作台

Node.js / DeepSeek API / SQLite

  • 围绕长视频课程难检索和示范难定位的问题，搭建课程转写、技巧笔记、资料检索与 AI 问答应用，将回答来源关联到课程原视频时间点。
  • 实现课程范围过滤、来源引用、片段循环与练习记录，使用 SQLite 保存练习计时，并将新课转写、笔记生成、视频裁切和入库沉淀为可复用 Skill。
  • 全项目带 56 项自动化测试。提问时只把问题和命中的课程文字摘录发给 DeepSeek，不上传音视频；API 密钥加密保存在本机。
