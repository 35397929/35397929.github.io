01

课程知识库问答与学习工作台

Node.js / DeepSeek API / SQLite

问题
长视频课程很难检索，想回看某个示范时找不到它在视频的哪一段。
做法
搭建课程转写、技巧笔记、资料检索与 AI 问答应用，实现课程范围过滤、来源引用、片段循环和练习记录，用 SQLite 保存练习计时。
结果
每个回答都能关联到课程原视频的时间点；新课转写、笔记生成、视频裁切和入库被沉淀成可复用的 Skill。全项目带 56 项自动化测试。

02

Queque Studio 公众号内容工作台

Codex Skill / Python

GitHub 仓库 ↗

问题
公众号文章从素材到发布，要反复拼接材料，格式也经常返工。
做法
把实际生产流程沉淀为可安装的 Skill，覆盖素材整理、事实核验、文章创作、人工复核、定稿冻结和封面配图，并编写来源台账、时间线和交付校验脚本。
结果
一次输出 Markdown、公众号 HTML、复制预览和 Word 图文包，减少拼接材料与格式返工。

03

国家电网办公智能体实战

课程研发与实操设计

问题
《用 AI 重塑工作流程》内训的学员，需要的是回到岗位就能用的练习。
做法
参与这门 3.5 小时、6 个模块的课程研发：把会议纪要、活动方案、宣传稿和汇报 PPT 等岗位任务拆成可跟做的练习，编写结构化提示词和操作案例；围绕制度问答与支部工作资料设计知识库示例。
结果
形成知识库、智能体和工作流改造的整套实操内容：用模拟材料搭制度问答助手（25 分钟）、建支部工作知识库（10 分钟），再画一张本岗位的工作流改造草图；知识库问答覆盖来源引用、缺资料回答和范围外问题的测试。
